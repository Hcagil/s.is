# SIS — Stay In Sync

Status: Android pre-alpha foundation and partial identity/authorization flow implemented; remote CI, live OAuth and physical-device verification remain open. Next: finish one-time cable/device validation and automate Google Play internal-test updates, then complete the text pilot for closed testing.
